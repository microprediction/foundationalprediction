Kairos

foundation · MLDI Lab · 50M · licence: Apache-2.0 · Model card · Code

Kairos (September 2025) is a parameter-efficient forecaster with a multi-patch decoder, trained on the PreSTS corpus of about 300 billion points.

How it was run

Run zero-shot on CPU with a fixed 128-length context from the Kairos code at commit 16eb4b9 and pinned weights revision b788434. Vendor defaults are kept (averaging with the flipped input) except preserve_positivity, which would truncate a signed change series and is off.

Nine native deciles. The tight arm reconstructs them with quantile_dist.

Against laplace, one step ahead

On the interactive leaderboard you can make Kairos the reference and see every other model paired against it, on any panel or subset of series; the tables below keep laplace as the reference.

Per series, Diebold–Mariano on the log score; a win is the model ahead beyond 1.96 standard errors, a loss laplace ahead, the rest draws. Median ΔLL is the model's log score minus laplace's, in nats per step; CRPS ratio is model over laplace (below 1 favours the model); coverage is the share of outcomes inside the central 90%. The methodology page has the protocol; the leaderboards place the model among the rest.
