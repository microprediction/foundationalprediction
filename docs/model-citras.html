CITRAS-FM

foundation · Hitachi · 7M · licence: CC BY-NC-SA 4.0 · Model card · Paper · Code

CITRAS-FM (EUSIPCO 2026) is a 7M-parameter covariate-informed forecaster with nine quantile outputs, run here on the target alone.

How it was run

Run zero-shot on CPU with a fixed 128-length context from the citras-fm code at commit a7f5648 (not on PyPI) and pinned weights revision 8633940, one call per context window. Weights are non-commercial.

Nine native deciles. The tight arm reconstructs them with quantile_dist.

Against laplace, one step ahead

On the interactive leaderboard you can make CITRAS-FM the reference and see every other model paired against it, on any panel or subset of series; the tables below keep laplace as the reference.

Per series, Diebold–Mariano on the log score; a win is the model ahead beyond 1.96 standard errors, a loss laplace ahead, the rest draws. Median ΔLL is the model's log score minus laplace's, in nats per step; CRPS ratio is model over laplace (below 1 favours the model); coverage is the share of outcomes inside the central 90%. The methodology page has the protocol; the leaderboards place the model among the rest.
