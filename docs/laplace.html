laplace

The reference model on every leaderboard here: an online forecaster that needs no training.

laplace updates its state with each new observation and issues a full predictive density for the next one. It is the default skater in the skaters package, pure Python with a compiled Rust core, and the same model has twins in JavaScript, R and Julia that agree with the Python to 1e-6. How it is built, from its transform chains to the tail splice, is in the skaters guide.

Why it is the reference

It sees every observation before forecasting the next, as a deployed forecaster would, and it costs microseconds. A model that cannot beat it on the next data point is not worth its weight for that job. laplace is also one of the two components of laplace++.
