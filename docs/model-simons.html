Simons

foundation · Abel AI Lab · 25M, 60M, 178M and 297M · licence: Apache-2.0 code; permissive weights · Model card (297M) · Code · Pretraining data

Simons is Abel AI Lab's family of nine-decile forecasters (Hugging Face repos 29 October 2026, code released 11 November 2026 as simons 0.1.0), in four sizes from 25M to 297M parameters.

How it was run

Run zero-shot on CPU with a fixed 128-length context, which the package left-pads to its own window. Pretrained on abel-lab/Simons-Pretrain, synthetic series plus real data; the published list has no FRED, FRED-MD or M4, and carries Monash copies. The four sizes score within 0.02 nats of each other on every stratum.

Nine native deciles; context 16,384 (25M, 60M) or 32,768 (178M, 297M). The tight arm reconstructs the deciles with quantile_dist, the original study's reconstruction.

Against laplace, one step ahead

On the interactive leaderboard you can make Simons the reference and see every other model paired against it, on any panel or subset of series; the tables below keep laplace as the reference.

Per series, Diebold–Mariano on the log score; a win is the model ahead beyond 1.96 standard errors, a loss laplace ahead, the rest draws. Median ΔLL is the model's log score minus laplace's, in nats per step; CRPS ratio is model over laplace (below 1 favours the model); coverage is the share of outcomes inside the central 90%. The methodology page has the protocol; the leaderboards place the model among the rest.
