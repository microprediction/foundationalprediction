# foundationalprediction

Which model should forecast the next data point? This site answers that one
question, with the one-step metric isolated, for the best foundation models
and a training-free online baseline, paired on identical series.

The pages under `docs/` are generated by `build.py` from the committed summaries,
cost and footprint measurements of the
[skaters](https://github.com/microprediction/skaters) repository. Nothing on
the site is typed by hand.

    SKATERS_DIR=../skaters python build.py

- `docs/index.html`: the next data point, one table per frequency
- `docs/methodology.html`: the protocol, the paired test, online baselines, the family split
- `docs/horizons.html`: per-horizon scores, each step isolated (filling in)
- `docs/gift.html`: the published GIFT-Eval numbers beside the added columns (filling in)

The older list of foundation-model resources that lived in this README is in
`resources.md`.
